# Журнал версий

Краткие вводные по каждой версии. Подробные журналы — в [docs/](docs/)
(`changes-0.2.md` … `changes-0.17.md`).

## 0.17

Язык подогнан под кодогенерацию моделями. Второй операнд любой бинарной
i32-операции принимает **литерал**: `ADD r0 5`, `EQ r1 0`, `SHL r2 3`, `MOV r3 42`.
Ошибки компиляции теперь объясняют, как чинить, а JSON-ошибки несут `line_text` —
исходную строку сбоя. Новые команды `test --init` (точный CSV-заголовок по
сигнатуре `main` и каналам ввода-вывода) и `fix` (репарация с записью на диск).
Машинный справочник [LLM.md](LLM.md) пригоден как системный промпт, а харнес
[tests/llm_eval/](tests/llm_eval/) измеряет классы ошибок модели.

## 0.16

Потолок регистров вырос с восьми до **256 на функцию** (`r0`…`r255`): регистры
стали частью локального кадра, поэтому рекурсия даёт каждому уровню свежий файл
автоматически. Рядом появился структурный сахар `STRUCT p x,y` — объявление
раскрывается в обычные одноячеечные локали `p.x`, `p.y` без новых опкодов и без
изменения ABI.

## 0.15

64-битная арифметика: отдельный класс **широких регистров `w0..w3`** с опкодами
`WLOAD`, `WADD`…`WMAX`, сравнениями `WEQ`/`WLT` (флаг — в обычный регистр) и
явными конверсиями `WIDEN`/`NARROW`. Арифметика заворачивается по модулю 2⁶⁴,
деление знаковое с отсечением к нулю, `NARROW` падает, если значение не
помещается в i32.

## 0.14

Снято главное ограничение графа вызовов: **рекурсия разрешена** — прямая
(`fact` вызывает себя) и взаимная (`even`/`odd`). Пределы перенесены из
компиляции во время выполнения: не больше 256 одновременно активных генов и не
больше 1 MiB локальных данных во всех активных кадрах вместе. Оба предела
одинаково проверяются в JIT и в интерпретаторе с одинаковыми сообщениями об
ошибках.

## 0.13

Строки научились выходить наружу: кодон `PRINT` пишет байты строки в канал,
который хост явно выдал программе (модель capabilities). Без выданного канала —
ошибка выполнения, а не скрытый доступ к системе. CLI печатает в stdout, `--json`
складывает вывод в поле `printed`, `verify` требует побайтового совпадения печати
в обоих бэкендах, а тестовый прогон по CSV печать отбрасывает.

## 0.12

Добавлены строки. Литералы `"text"` с экранированием, длина, доступ к байту,
конкатенация и сравнение — с жёсткими лимитами памяти и одинаковым поведением
в JIT и интерпретаторе. Строки неизменяемы; регистры хранят хэндлы, а не указатели.

## 0.11

Добавлены две проверки доверия. Команда `verify` прогоняет программу в JIT
и в эталонном интерпретаторе и требует полного совпадения результата, выходного
списка или ошибки. Горячее обновление получило шлюз по тестам:
`reload file.dna --gate cases.csv` публикует новую версию, только если весь CSV
зелёный; иначе активной остаётся прежняя. В C API добавлена `bio_runtime_publish`
для собственных проверок перед публикацией.

## 0.10

`--repair` получил безопасный режим репарации. Однозначно пропущенные
служебные `_` восстанавливаются, а неоднозначные кодоны не получают выдуманных
значений: они попадают в карантин и при достижении останавливают запуск с файлом,
строкой и журналом ремонта. Команда `check --repair --json` выдаёт этот журнал.
Формат остаётся триплетным; дополнительных библиотек у готового приложения нет.
