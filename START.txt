Codons 0.7.0 — быстрый запуск в Windows x64

Откройте PowerShell в папке распакованной программы.
Компилятор C, Python и установка не нужны.

1. Создайте первую программу:
   .\codons.exe new hello.dna

2. Передайте ей два числа:
   .\codons.exe run hello.dna 10 20
   Результат: 30

3. Попробуйте готовые примеры:
   .\codons.exe run examples\price.dna 3 250
   Результат: 750
   .\codons.exe run examples\threshold.dna 75 60
   Результат: 1 (порог пройден)
   .\codons.exe run examples\clamp.dna 150 100
   Результат: 100

4. Ветвления и циклы:
   .\codons.exe run examples\sum.dna 10
   Результат: 55 (сумма от 1 до 10)
   .\codons.exe run examples\factorial.dna 5
   Результат: 120
   .\codons.exe run examples\branch.dna -4 9
   Результат: 9 (выбор большего числа через ветвление)

Триплеты переходов: LABEL name _, JMP name _, JZ r0 name, JNZ r0 name.
Метки принадлежат своей функции. JZ переходит при нуле, JNZ — при ненулевом значении.

Защита от зависания:
   .\codons.exe run examples\infinite.dna
Ожидаемая ошибка: execution budget exhausted (limit: 1000000 steps).
Весь запуск, включая вложенные вызовы, ограничен миллионом шагов.
Следующий запуск получает новый лимит. В режиме live можно продолжать работу.
Большое конечное вычисление тоже может исчерпать лимит.

5. Проверьте программу по примерам из CSV:
   .\codons.exe test examples\sum.dna examples\sum.csv
   Результат: Tests: 4 total, 4 passed, 0 failed
   .\codons.exe test examples\price.dna examples\price.csv --json

Пример CSV для одного входного числа:
   arg1,expected
   10,55
   0,0
   -5,0

Заголовок обязателен: expected для 0 входов, arg1,expected для 1 входа,
arg1,arg2,expected для 2 входов. Файл UTF-8, разделитель — запятая.
PASS означает совпадение, FAIL — неверный ответ, ERROR — ошибку выполнения.
Показаны номера строк, входы, ожидаемые и фактические ответы.
После FAIL/ERROR проверка продолжается; каждый пример получает новый лимит шагов.
При ошибке формата CSV ни один пример не запускается.
Код завершения: 0 — всё прошло, 1 — есть ошибка, 2 — неверная команда.
Не более 1000 примеров в одном CSV. Пустой набор считается ошибкой.

6. Деление, логические и битовые операции:
   .\codons.exe run examples\divide.dna -7 3
   Результат: -2 (округление к нулю)
   .\codons.exe run examples\remainder.dna -7 3
   Результат: -1 (знак делимого)
   .\codons.exe run examples\logic.dna 8 2
   Результат: 1 (оба числа ненулевые)
   .\codons.exe run examples\flags.dna 8 2
   Результат: 0 (общих единичных битов нет)
   .\codons.exe run examples\bits.dna -1
   Результат: 32 (число единичных битов)
   .\codons.exe test examples\divide.dna examples\divide.csv
   .\codons.exe test examples\bits.dna examples\bits.csv

Новые команды: DIV, MOD; AND, OR, XOR, NOT; LAND, LOR, LXOR, LNOT; SHL, SHR, SAR.
Двоичная операция: DIV r0 r1. Одноместная: NOT r0 _ или LNOT r0 _.
Результат записывается в первый регистр. Логические операции дают 0 или 1.
Число бит для сдвига — от 0 до 31. SHR заполняет нулями, SAR сохраняет знак.
Деление на ноль и -2147483648 DIV -1 сообщают ошибку с файлом и строкой.
-2147483648 MOD -1 возвращает 0. После ошибки live и CSV-проверки продолжают работу.

7. Переменные и массивы:
   .\codons.exe run examples\variables.dna 10
   Результат: 55 (сумма с именованной переменной total)
   .\codons.exe run examples\array_sum.dna 2 3
   Результат: 392 (заполнить 16 элементов и сложить их в обратном порядке)
   .\codons.exe run examples\array_at.dna 7
   Результат: 49 (элемент таблицы квадратов)
   .\codons.exe test examples\array_sum.dna examples\array_sum.csv
   Результат: Tests: 6 total, 6 passed, 0 failed

Объявления в начале функции: VAR total 0, ARRAY items 16.
Переменная: SET total r0, GET r0 total.
Массив: ASET items r1,r0, AGET r0 items,r1, LEN r2 items.
В ASET первый регистр — индекс, второй — значение. Запятые без пробелов.
Индексы начинаются с нуля. Выход за границы сообщает файл, строку и неверный индекс:
   .\codons.exe run examples\array_at.dna 8
   Ожидаемая ошибка: array index 8 out of bounds (допустимы 0..7).

Данные локальны для каждого вызова; массивы начинают с нулей.
Инициализация каждой ячейки расходует один шаг общего лимита.
До 64 объявлений и 65536 ячеек i32 на функцию; до 1 MiB данных на активную цепочку вызовов.
Размер массива фиксирован. Состояние между запусками не сохраняется.

8. Списки чисел из файлов:
   .\codons.exe run examples\list_sum.dna --input examples\numbers.txt
   Результат: 18
   .\codons.exe run examples\list_filter.dna 5 --input examples\numbers.txt --output filtered.txt
   Результат: 3; в filtered.txt записаны 7, 7, 12 по одному числу на строку.
   .\codons.exe run examples\list_sort.dna --input examples\numbers.txt --output sorted.txt
   Результат: 7; в sorted.txt записаны -9, -3, 0, 4, 7, 7, 12 по одному числу на строку.

Внутри программы: READ items r0 читает список в массив и возвращает длину в r0.
WRITE items r0 подготавливает первые r0 элементов для сохранения.
READ повторно читает тот же список. Последний WRITE задаёт весь результат.
Каждая команда расходует один шаг плюс количество переносимых элементов.

Вход: UTF-8, одно число i32 на строку; пустые строки и пробелы по краям разрешены.
Пустой файл допустим. До 65536 чисел и 1 MiB на файл; массив должен вместить весь список.
В примерах сумма/фильтр вмещают 4096 чисел, сортировка — 256.
Результат сохраняется только после успешного выполнения. Существующие файлы не
перезаписываются: при повторном запуске выберите новый путь --output.
Пустой WRITE создаёт пустой файл. Если WRITE не выполнен, выходной файл не создаётся.
Флаги --input и --output работают в run и interpret, включая --json.
На экран по-прежнему выводится число из RET, список сохраняется в файл.

Проверка файла: .\codons.exe check hello.dna
Ответ для скрипта или AI-агента: .\codons.exe run hello.dna 10 20 --json
Справка: .\codons.exe --help

Горячее обновление:
   .\codons.exe live examples\main.dna
Затем введите:
   run
   reload examples/updated.dna
   run
   quit
Результат меняется с 30 на 42 в том же процессе.

В исходном проекте бинарник находится в build\codons.exe.
Подробнее о языке и ограничениях — в README.md.
