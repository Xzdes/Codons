# Codons 0.14 — рекурсия с бюджетом глубины

Дата: 2026-03-22. Ветка 0.14 снимает ограничение «граф вызовов — DAG»: прямая и
взаимная рекурсия разрешены, а пределы перенесены из времени компиляции во время
выполнения.

## Что изменилось

### Рекурсия разрешена

`CALL` может образовывать циклы: `fact` вызывает себя, `even`/`odd` вызывают
друг друга, мёртвый ген может содержать рекурсивный вызов. Каждый вызов
получает свежий кадр локалей: значения `VAR` и содержимое `ARRAY` не делятся
между уровнями рекурсии.

### Пределы — во время выполнения

- **Глубина**: не больше 256 одновременно активных генов, включая `main`.
  Превышение — `call depth limit reached (256 active genes)`.
- **Память кадров**: не больше 262144 ячеек i32 (1 MiB) локальных данных во
  всех активных кадрах вместе. Превышение —
  `call frame memory exhausted: need N more cells, M left this run`.

Обе ошибки содержат файл и строку и побайтово совпадают в JIT и интерпретаторе.
Проверки выполняются до входа в вызываемый ген, поэтому частичного кадра не
остаётся. Для ацикличных программ ничего не изменилось: статический подсчёт
шагов и памяти сохранён, пул выделяется по точной оценке.

Сняты статические пределы `apoptosis: recursive call cycle` и
`apoptosis: call depth exceeds 64`: длинные цепочки вызовов легальны, а фактическая
глубина контролируется в рантайме. Рекурсивная программа получает
`dynamic_steps: true` в статистике (число шагов статически неизвестно).

### Реализация

`BioExecution` дополнен счётчиками `frame_used`, `depth`, `frame_cells`; оба
бэкенда поддерживают инвариант «база локалей = пул + frame_used - local_cells»
и выполняют одну и ту же последовательность проверок на `CALL`: размер массива,
глубина, память, фиксация, вызов, безусловный откат, распространение сбоя.
JIT эмитирует проверки инлайн теми же гардами, что и для остальных лимитов;
срыв компиляции не требуется — адреса вызовов уже патчатся после эмиссии всех
генов, поэтому взаимная рекурсия не потребовала изменений связывания.

## Тесты

- C: факториал (прямая), чётность (взаимная), изоляция `VAR` и `ARRAY` по
  кадрам, точная граница глубины (254 → ок, 255 → ошибка), исчерпание пула
  кадров раньше предела глубины, статическая цепочка на всю глубину (256
  генов), статистика `dynamic_steps` для рекурсивных программ, паритет
  сообщений об ошибках между бэкендами.
- CLI: факториал через `run`/`interpret`/`verify`, `dynamic_steps` в JSON
  статистике, ошибки глубины и пула с файлом и строкой, мёртвая рекурсия в
  удалённом гене.
- Фаззер и весь прежний набор: без изменений поведения для ацикличных программ
  (800 программ на двух сидах — полное совпадение бэкендов).

## Совместимость

Программы 0.13 работают без изменений; программы, ранее отклонявшиеся как
«recursive call cycle», теперь компилируются и выполняются. Сообщение
«apoptosis: call depth exceeds» исчезло вместе со статическим пределом.
