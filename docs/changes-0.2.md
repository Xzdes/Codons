# Codons 0.2.0

Следующий законченный этап после прототипа 0.1: простой консольный инструмент
для небольших целочисленных вычислений и встраивания в AI-инструменты.

- Входные данные: `run file.dna 10 20`, сигнатуры `main` с 0–2 аргументами.
- Операции `EQ`, `LT`, `MIN`, `MAX` с определённой знаковой семантикой.
- `new file.dna` создаёт рабочий пример и не перезаписывает существующие файлы.
- `--json` возвращает структурированные успехи, ошибки и статистику.
- `check`, `dump`, `interpret` работают без подготовки JIT.
- `dump` выдаёт читаемый, повторно разбираемый исходник с раскрытыми импортами.
- Русские имена файлов и каталогов, UTF-8 C API и UTF-16 Windows API.
- Бюджет 1 000 000 выполняемых кодонов с учётом вложенных вызовов.
- Переносимая ZIP-сборка с приложением, примерами и инструкцией.

Формат `.dna` совместим с 0.1. Экспериментальный C API выполнения изменён:
функции теперь принимают входные аргументы, указатель результата и диагностику
и возвращают статус. Горячая замена по-прежнему публикует полный снимок программы.

Проверки: случайные программы, граничные значения сравнений, точная граница бюджета,
экспоненциальный граф вызовов, параллельные обновления, пользовательские сценарии CLI,
JSON, Unicode и запуск без компилятора в PATH. Преимущество Codons над C для
генерации нейросетью ещё не измерялось.

Ветвления, циклы, сложные типы, оптимизатор и миграция состояния в эту версию
не добавлялись. Следующий этап стоит выбирать по реальным сценариям использования.
