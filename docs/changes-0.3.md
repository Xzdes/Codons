# Codons 0.3.0

Ветвления и циклы с прежним форматом: три поля в каждой значимой строке.

- `LABEL name _` задаёт локальную метку, `JMP name _` выполняет переход.
- `JZ rN name` переходит при нуле, `JNZ rN name` — при любом ненулевом значении.
- Проверяются цели переходов, дубликаты меток, присваивание регистрам на всех
  достижимых путях и отсутствие проваливания в конец функции.
- Миллион исполняемых кодонов на один запуск, совместно со всеми вложенными
  вызовами. Лимит проверяется в машинном коде и интерпретаторе.
- При исчерпании лимита возвращается ошибка с файлом и строкой; следующий запуск
  снова доступен. Параллельные запуски имеют независимые счётчики.
- Примеры: сумма от 1 до n, факториал, выбор большего числа через ветвление,
  намеренно бесконечный цикл для проверки защиты.

Проверены точная граница лимита, превышение на один шаг, общий бюджет нескольких
вызовов, восстановление после ошибки, параллельное выполнение, вложенные циклы
и дальние переходы. Сто воспроизводимо сгенерированных программ с циклами, ветками
и вызовами сравниваются с интерпретатором и отдельным расчётом на Python.
Существующие проверки арифметики, обновлений и пользовательских команд сохранены.

Исходники 0.2 и сигнатуры публичных функций выполнения совместимы. Структура
`BioStats` расширена: C-приложения нужно пересобрать. В JSON `execution_steps`
теперь может быть `null`, когда есть достижимые переходы; `dynamic_steps` сообщает
об этом явно, `execution_limit` задаёт лимит. Это статическая оценка, не фактический
счётчик выполненных шагов. Сырые байты `emit` требуют внутреннего контекста выполнения;
для встраивания используйте публичный C API.

`check` не доказывает завершение циклов, а лимит может остановить и большое конечное
вычисление. Метки не расходуют шаги; вызовы, переходы и возврат расходуют.
Рекурсия остаётся запрещённой. Новых зависимостей, оптимизирующего IR, фоновых
контролирующих потоков и дополнительных настроек не добавлено.
