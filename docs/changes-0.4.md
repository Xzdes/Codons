# Codons 0.4.0

Добавлена команда `codons test program.dna cases.csv` для проверки программы
по таблице входных чисел и ожидаемых результатов.

- Обязательный заголовок: `expected`, `arg1,expected` или `arg1,arg2,expected`,
  в зависимости от числа аргументов `main`.
- Одна компиляция и последовательное выполнение всех примеров.
- Отчёт `PASS` / `FAIL` / `ERROR` с номером строки CSV, входами и ожидаемым ответом;
  при несовпадении показан фактический ответ, при ошибке — причина.
- Каждый пример получает новый лимит исполнения. Ошибка одного не мешает остальным.
- Весь CSV проверяется до запуска; пустой набор считается ошибкой.
- UTF-8 и BOM, русские пути, LF/CRLF, пустые строки, пробелы вокруг значений,
  числовые ячейки в двойных кавычках. Разделитель — запятая.
- `--json`: результаты каждого примера и итоговые счётчики; CSV-ошибки содержат
  отдельные код, путь, строку и номер столбца.
- Код завершения 0 — всё прошло, 1 — ошибка/несовпадение, 2 — неверная команда.
- Готовые CSV для `main`, `sum`, `price`, `factorial` включены в ZIP.

Границы: 1000 примеров, 1 MiB файла, 511 байт на физическую строку до LF.
Многострочные поля, текстовые значения, комментарии и разделитель `;` не поддерживаются.

Проверки включают все три сигнатуры, границы i32 и арифметическое переполнение,
неверные ответы, продолжение после исчерпания бюджета, повреждённые файлы,
структуру JSON, точные номера строк и столбцов, границы размеров и запуск
без инструментов разработки в PATH. Сохранены проверки предыдущей версии.

Триплетный синтаксис и C API не изменены. Команда `test` проверяет только переданные
примеры и не запускается автоматически при `reload`. Новых зависимостей нет.
