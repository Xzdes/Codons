# Codons 0.5.0

Тринадцать новых операций, все в прежнем триплетном формате:

- `DIV rN rM`, `MOD rN rM` — знаковое деление к нулю и остаток со знаком делимого.
- `AND`, `OR`, `XOR` — побитовые двоичные операции; `NOT rN _` инвертирует 32 бита.
- `LAND`, `LOR`, `LXOR` — логические двоичные операции; `LNOT rN _` — отрицание.
  Ноль считается ложью, любое ненулевое значение — истиной, результат всегда 0/1.
- `SHL`, `SHR`, `SAR` — сдвиг влево, вправо с нулями и вправо со знаком.

Результат записывается в первый регистр. Оба операнда двоичной операции читаются
до записи, включая случай совпадения регистров. Логические операции читают оба
регистра; для условного исполнения команд используются переходы.

Нулевой делитель — ошибка для DIV и MOD. `-2147483648 DIV -1` — ошибка переполнения;
`-2147483648 MOD -1` равен 0. Сдвиги принимают счётчик 0..31 и отклоняют остальные
значения. SHL отбрасывает вышедшие биты. Сложение, вычитание и умножение по-прежнему
переполняются по модулю 2³². Пропущенное `_` в NOT/LNOT не восстанавливается `--repair`.

Ошибки имеют координаты исходной операции и передаются через вложенные вызовы.
C API возвращает неуспех без изменения выходного числа. `run`/`interpret` завершаются
с кодом 1, `live` остаётся доступен, `test` отмечает ERROR и выполняет следующий пример.
Каждая операция расходует один шаг; исчерпанный лимит проверяется до самой операции.

Примеры с CSV: divide, remainder, logic, flags, bits. Последний считает единичные
биты во всём 32-битном представлении, включая отрицательные числа.

Проверены все регистры и совпадающие операнды, крайние i32, знаки деления и остатка,
границы сдвигов, логические таблицы и 100 воспроизводимых смешанных программ.
Результаты машинного кода и интерпретатора сравниваются с отдельным расчётом.
Проверены вложенные вызовы, параллельные ошибки, восстановление после ошибки,
CSV, нормализованный дамп и сохранение защиты от бесконечных циклов.

Новых зависимостей и изменений публичного C API нет. Формат `.dna` предыдущих
версий совместим. Внутренний контекст сырых байтов `emit` расширен видом ошибки;
встраивание следует выполнять через публичный C API.
