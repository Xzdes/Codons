# Codons 0.6.0

Локальные переменные и массивы i32, семь новых команд в прежнем триплетном формате:

| Команда | Действие |
|---|---|
| `VAR total 0` | Объявить переменную с начальным значением |
| `ARRAY items 16` | Объявить массив фиксированной длины, заполненный нулями |
| `SET total r0` | Записать регистр в переменную |
| `GET r0 total` | Прочитать переменную |
| `ASET items r1,r0` | Записать значение r0 по индексу r1 |
| `AGET r0 items,r1` | Прочитать элемент по индексу r1 |
| `LEN r0 items` | Получить длину массива |

Объявления идут сразу после GENE, до инструкций и меток. Начальные значения и длины
задаются десятичными константами. Имена принадлежат функции; переменные и массивы
имеют общее локальное пространство имён. Арифметика по-прежнему работает через регистры.

Каждое обращение к массиву проверяет диапазон 0..длина−1 до чтения или записи.
Ошибка содержит индекс, допустимые границы, файл и строку. Нативное выполнение
и интерпретатор сообщают одинаковые ошибки. Выходное число C API остаётся прежним;
CSV-проверки и live могут выполнить следующий запуск после ошибки.

При каждом вызове данные инициализируются заново, независимо от родительских
и параллельных вызовов. Инициализация каждой ячейки учитывается в миллионе шагов.
На функцию разрешено 64 объявления и 65536 ячеек i32 суммарно. Активная цепочка
вызовов ограничена 262144 ячейками (1 MiB). Размер памяти проверяется до выполнения;
на запуск выделяется один блок, последовательные вызовы переиспользуют его участки.

Примеры с CSV: variables, array_sum, array_at. Проверены границы индексов, памяти
и шагов, совпадающие регистры, вложенные вызовы, независимость потоков, восстановление
после ошибки и обновление программы с изменением локальных данных. 120 новых
воспроизводимых программ сравнивают оба режима с независимым расчётом на Python.

Новых зависимостей нет. Публичный C API и прежние программы совместимы.
Внутренний ABI машинных байтов emit изменился: R9 передаёт область данных,
контекст ошибок расширен, стековый кадр — 88 байт. Для встраивания используется C API.
Глобальные переменные, изменение размера и передача массивов пока не поддерживаются.
