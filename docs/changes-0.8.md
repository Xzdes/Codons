# Codons 0.8.0

Массивы можно передавать в функции, сохраняя триплеты:

```text
GENE sort i32/1
PARAM items r0
```

Вызов `CALL sort values,r3` передаёт первые r3 элементов массива values,
а длину записывает во входной r0. `CALL filter values,r3,r4` также передаёт
число из r4 во входной r1; такая функция объявляется как i32/2.
Результат остаётся числом i32 в r0; остальные регистры вызывающего сохраняются.

Одна команда PARAM на функцию, среди начальных VAR/ARRAY. У main PARAM запрещён:
входные списки по-прежнему читаются через ARRAY/READ. Новых типов, указателей
в исходном языке, зависимостей и изменений публичного C API нет.

Массив передаётся без копирования: изменения элементов видны вызывающей функции.
До вызова проверяется длина от нуля до доступной границы. LEN у PARAM возвращает
переданную длину, которая сохраняется независимо от дальнейших изменений r0.
AGET/ASET и READ/WRITE проверяют эту границу. Передача дальше может уменьшить
доступную часть, но не расширить её. Для пустой части нет допустимых индексов.
PARAM не расходует собственные ячейки и шаги инициализации; лимит объявлений —
прежние 64, весь запуск ограничен общим миллионом шагов. Ошибки содержат файл и строку.

Пример `list_pipeline.dna`: чтение -> filter -> sort -> запись.
Модуль `lists.dna` содержит filter, sort и sum для повторного использования.
При пороге 5 и входе numbers.txt получается новый файл с числами 7, 7, 12,
на экран возвращается количество 3. Пример рассчитан на 256 входных чисел.

Дамп сохраняет PARAM и вызовы с массивами. В reload наличие PARAM стало частью
проверяемой сигнатуры; переименовать параметр или изменить тело функции можно.
Кадр машинного кода увеличен с 88 до 104 байт для сохранения указателя и длины;
описание раскрутки стека Windows обновлено вместе с ним.

Проверки охватывают вложенные вызовы и сужение, пустые части, отрицательные и
предельные длины/индексы, сохранность соседних данных, все пары регистров аргументов,
точную границу миллиона шагов, параллельные запуски и обновления. Цепочка проверена
на 45 наборах, ещё 40 проверяют фильтр/сортировку/сумму и сохранность хвоста по Python.
Все прежние тесты сохраняются. CLI-команда test пока работает с числовыми CSV,
файловые флаги доступны только для run/interpret.
