# Codons 0.9.0

`codons test` умеет проверять файловые сценарии. Новый CSV для программы с одним
числовым аргументом:

```csv
arg1,input,expected,expected_output
5,numbers.txt,3,numbers_filtered.txt
```

Для 0 аргументов заголовок input,expected,expected_output; для 2 перед input
добавляются arg1,arg2. Старые числовые CSV продолжают работать с прежними отчётами.

Пути списков считаются от каталога CSV; поддерживаются абсолютные пути,
кириллица, пробелы и пути с запятыми в кавычках. Пустая ячейка пути — ошибка CSV;
пустой список задаётся пустым файлом. CSV целиком проверяется до первого запуска,
списки читаются перед своим примером. Ошибка входного файла или эталона отмечается
как ERROR с именем поля, путём и строкой файла при наличии; следующие примеры выполняются.

PASS требует совпадения RET и всего выходного списка: длины, порядка и значений.
FAIL показывает ожидаемую и фактическую длину и первое различие; номера элементов
с единицы. Лишние/пропущенные элементы обозначаются <missing>, в JSON — null.
При ошибке исполнения частичный WRITE не сравнивается. Отсутствие WRITE — ERROR,
даже для пустого эталона. После ERROR/FAIL проверка продолжается со свежим бюджетом
и данными следующего запуска.

Результат сравнивается в памяти через существующий BioIO. Входы и эталоны только
читаются, выходные и временные файлы не создаются. Буферы освобождаются после
каждого примера, а не хранятся на весь набор. Лимиты CSV и списков прежние.

JSON для файлового CSV добавляет input, expected_output и output: matched,
expected_count, actual_count, необязательный difference с element, expected, actual.
При ERROR нет actual/output. Ошибки файлов имеют stage=file и поле field,
ошибки исполнения — stage=run; пустой путь — CSV code=path.

Готовый набор examples/list_pipeline.csv содержит 8 сценариев: обычный список,
пустой вход, повторы, отрицательные числа, отбор всех/ни одного, крайние i32,
одно число. Запуск:

```powershell
.\codons.exe test examples\list_pipeline.dna examples\list_pipeline.csv
```

Добавлены проверки новых заголовков и прежнего формата, путей и Unicode,
различий числа/длины/порядка, ошибок файлов, пустого WRITE, точной границы бюджета,
предела 65536 чисел и 1000 примеров, сохранности файлов. Ещё 50 наборов цепочки
сравниваются с независимыми эталонами Python через файловый CSV.
Триплетный язык, проверки границ, машинный код и публичный C API не изменены.
